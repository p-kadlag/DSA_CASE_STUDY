# Banking Transactions Mini Statement Generator

A robust, menu-driven Banking Transaction System written in C. This project simulates core banking functionalities, including account management, transactions, and the generation of a rolling mini-statement. 

This project was developed as a case study demonstrating the practical application of C programming core concepts.

## 🚀 Features

* **Account Management:** Create new bank accounts and delete existing ones. Data is persistently stored in a local binary file.
* **Deposits & Withdrawals:** Perform basic transactions with validation (e.g., checking for sufficient balance before withdrawal).
* **Rolling Transaction Log:** Automatically maintains a history of the last 5 transactions for every user account.
* **Mini Statement Generation:** View a formatted table of the latest transactions directly in the terminal.
* **Statement Export:** Automatically exports the user's mini-statement to a readable `.txt` file (e.g., `statement_101.txt`).

## 🧠 Key Concepts Demonstrated

This project fulfills specific academic case study requirements, highlighting the following C programming concepts:
* **Structures (`struct`):** Used to model `Account` and `Transaction` data securely.
* **Arrays:** Utilized to maintain the rolling log of recent transactions.
* **File Handling:** Binary file operations (`fread`, `fwrite`, `fseek`) to maintain a persistent database (`bank_accounts.dat`), and text file operations (`fprintf`) for statement generation.
* **Menu-Driven Architecture:** A continuous `while` loop paired with `switch-case` logic for seamless user navigation.

## 🛠️ How to Compile and Run

### Prerequisites
You need a C compiler (like GCC) installed on your system.

### Compilation
Open your terminal and navigate to the directory containing `main.c`. Run the following command:

```bash
gcc main.c -o banking_system
```

### Execution
Run the compiled executable:

* **On Linux/macOS:**
  ```bash
  ./banking_system
  ```
* **On Windows:**
  ```cmd
  banking_system.exe
  ```

## 📁 File Structure

* `main.c`: The main source code file containing all logic.
* `bank_accounts.dat`: A binary database file automatically generated by the program upon first account creation to store user data persistently. *(Note: This file is created at runtime)*
* `statement_[acc_num].txt`: Text files generated by the program when a user requests a mini-statement.
